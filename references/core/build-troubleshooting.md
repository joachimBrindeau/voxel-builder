# Elementor Build Troubleshooting


| Symptom | Likely cause | Fix |
|---|---|---|
| `elementor:lint` reports `unknown-prop` for a recently-renamed key | Memorised V3 prop name | Re-query schema, use new name |
| Dynamic tag renders as literal `@post(title)` text | Missing `@tags()...@endtags()` wrapper on a string-type prop | Wrap the value |
| Image renders empty | Image `$$type` wrong; needs `{$$type: image, value: {src: {$$type: vx \| number, value: ...}}}` | Query `--prop <key>` for exact shape |
| Feed renders empty | CPT lacks `search.filters` + `search.order`, or index table missing | Add to blueprint, run index table create + reindex |
| Form submit doesn't update feed | `ts_post_to_feed` references stale widget ID | Update to current feed widget's `id` |
| Single ef-card rendered with extra spacing | Wrapper container present | `wpdev elementor:strip:wrappers <site> --fix --yes` (site-wide; snapshot first, approved cleanup only) |
| CSS not applied after write | `--save` failed or was omitted | Re-run import with `--save`, or open editor URL and click "Update" |
| Opening a composite content row throws `Cannot read properties of undefined` immediately after an editor script split | A classic script reused one global name for its private initialized module and its smaller `window.*` export; assigning the export replaced the private module through the shared global binding | Give the private module a distinct binding, preserve the public API name, and add a real classic-script-context regression test |
| A page will not scroll while the pointer sits over a carousel / pager, or a nominally vertical trackpad swipe moves nothing | A trackpad swipe carries horizontal jitter, so the browser routes the gesture to the nearest horizontal scroller (the pager track); `scroll-snap-type: x mandatory` then refuses any resting place other than a snap point and undoes the delta — neither track nor page moves | Resolve the dominant axis explicitly in the wheel handler: vertical intent scrolls the window (convert `deltaMode` lines/pages to pixels first), horizontal intent steps the track by a whole snap page. Cover it with a **vertical** wheel assertion — the horizontal direction already works natively and cannot prove the fix |
| A dropdown / popover / tooltip opens, then stays pinned in the viewport while its anchor scrolls away, or lands at the top-left corner | A placement scheduler was registered directly as a `scroll`/`resize` listener, so it receives an `Event` where it expects an anchor rect; every coordinate computes to `NaN`, the style assignment is rejected, and the layer keeps its last good position | Accept an anchor argument only when it actually carries rect edges, and fall back to re-measuring the anchor otherwise. Unit-test the scheduler with an `Event` argument — the DOM-level symptom is invisible to a screenshot |
| A page/template renders as an empty `.elementor` shell — no EF markup at all, no PHP error | The plugin is active but registered **zero** elements: its `vendor/autoload.php` is missing, so `elementor-framework.php` soft-fails (it deliberately does not fatal) and no widget class ever loads | Probe registration before suspecting the widget or the data: an empty `ef-*` list from `Plugin::$instance->elements_manager->get_element_types()` means the bootstrap died. Run `composer install` **in the plugin dir**, then `composer dump-autoload` so the dev autoloader (Twig et al.) is registered too |
| PHPUnit reports many `Class "…" not found` errors that no source change explains | `vendor/` was restored with `composer install` but the **dev** autoload map was never regenerated | `composer dump-autoload` in the plugin dir. Confirm with a `Found`-count before/after; do not "fix" the tests |
| `elementor:codegen --check` is green but `elementor:codegen:verify <site>` reports a prop present in PHP yet missing from TS | The offline gate diffs the extractor against **its own output**, so anything the extractor cannot see is consistently absent from both sides. Only the live PHP runtime knows the truth | Treat `codegen:verify` as the authority for PHP↔TS agreement. Find why the extractor skipped the entry (e.g. an action field spec authored as a raw `[ 'key' => … ]` literal instead of a `$mk( … )` call), fix the **source authoring**, regenerate, and add a completeness gate so the next silent skip fails the build |
