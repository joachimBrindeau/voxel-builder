# `sameAs` Identity Links

Use this reference for any Voxel CPT whose schema entity can carry Schema.org
`sameAs`. It defines the field model and acceptance rules; the mutation process
lives in [`../../workflows/identity-linking.md`](../../workflows/identity-linking.md).

## Canonical Field Model

New CPTs use a `sameAs` repeater with one required URL subfield:

```json
{
  "key": "sameAs",
  "type": "repeater",
  "label": "Same As",
  "required": false,
  "props": {
    "max": 30,
    "fields": [
      {
        "key": "url",
        "type": "url",
        "label": "URL",
        "required": true
      }
    ]
  }
}
```

Use the exact live field shape returned by `wpdev voxel:fields`; do not guess the
stored config envelope. Existing sites may keep a different field key, but the
schema resolver must name that actual Voxel field. Do not add provider, label,
or source-type subfields unless a real second consumer requires them.

## Identity Is Not Citation

`sameAs` says that another URL identifies the same entity. A `sources`/citation
row only supports a claim. Never promote a citation merely because it mentions
the record.

Accept a URL only when all are true:

- The target is the same person, organization, place, product, creative work,
  event, concept, or other entity represented by the record.
- The URL is canonical, public, stable, HTTPS, and not a search/results URL.
- Redirects land on the intended entity, not a broader topic or another entity
  with the same name.
- Ambiguous names are resolved with record context such as entity type, location,
  parent organization, dates, identifiers, or the record definition.
- The evidence packet records why equivalence is defensible.

Reject:

- Sources that are merely related, descriptive, comparative, or evidentiary.
- Categories, lists, tags, search pages, disambiguation pages, and sections whose
  parent page represents a broader entity.
- Parent classes for a subtype, cities for a prefecture, brands for a product,
  people for an organization, or any other broader/narrower substitution.
- Commercial directories, scraped profiles, autogenerated pages, and URLs whose
  ownership or canonical status cannot be verified.

## Provider Policy

- **Wikipedia + Wikidata:** when an exact Wikipedia article exists, store its
  canonical article URL and the corresponding Wikidata `Q` item. Confirm the
  article and `Q` item represent the same entity. Wikidata-only is valid when no
  exact Wikipedia article exists.
- **Official identity URLs:** for people, organizations, products, places,
  events, and creative works, official websites or verified official profiles
  may be accepted when ownership and entity equivalence are proven.
- **Other knowledge graphs:** accept only stable entity pages with transparent
  identity semantics. Do not add a provider merely to increase row count.
- **Languages:** prefer the site's language, then canonical English when it is
  the clearest shared identity. Do not add multiple language editions of the
  same Wikipedia article unless a downstream consumer explicitly needs them.

Normalize duplicates after redirects and URL canonicalization. A Wikipedia URL
and its linked Wikidata item are intentionally distinct rows; tracking parameters,
mobile subdomains, HTTP variants, and duplicate language redirects are not.

## Schema Projection

For the canonical field model, project repeater rows to a flat URL array:

```json
"sameAs": {
  "@each": "voxel:sameAs",
  "@map": "row:url"
}
```

Use `voxel:<field-key>`, not `meta:<field-key>`, for Voxel fields. Place the
property on the schema node that represents the record entity, not automatically
on `WebPage`. Empty repeaters should prune the property entirely.

## Required Decision Artifact

Keep one row per audited record, including explicit no-match decisions:

```json
{
  "id": 123,
  "title": "Example entity",
  "decision": "accepted",
  "sameAs": [
    { "url": "https://en.wikipedia.org/wiki/Example" },
    { "url": "https://www.wikidata.org/wiki/Q123" }
  ],
  "evidence": "Exact entity; canonical article resolves to Q123"
}
```

Use `decision: "skipped"`, an empty `sameAs` array, and a concrete reason when no
precise identity exists. Coverage means every record has a decision, not that
every record receives a URL.
